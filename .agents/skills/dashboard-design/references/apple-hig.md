# Apple Design Guidance for the Dashboard

Apple's Human Interface Guidelines cover design for Apple platforms. Apply the general principles to the Dashboard's web markup, standard controls, and browser viewport sizes.

- Prioritize the action that matters most in the current state. Keep the hierarchy quiet while users monitor the feed. If a connection fails, give users a clear way back to the source settings. [Apple Design Principles](https://developer.apple.com/design/human-interface-guidelines/design-principles)
- Keep the reading area and controls visually distinct. In a narrow window, sections can stack in one column while preserving their order and keeping actions easy to find. [Apple Layout](https://developer.apple.com/design/human-interface-guidelines/layout)
- Use text size, weight, and color to convey relative importance. When text grows, keep the levels of hierarchy distinguishable and preserve wrapping, especially for long names and messages. [Apple Typography](https://developer.apple.com/design/human-interface-guidelines/typography)
